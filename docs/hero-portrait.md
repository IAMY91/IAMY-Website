# Hero portrait

The homepage uses the original portrait published on Ilya Alexander Yacine's CREATE speaker profile:

- Profile: https://wemaco.eu/create-speaker/ilya-alexander-yacine/
- Original image: https://wemaco.eu/wp-content/uploads/2024/03/Ilya.jpg
- Local asset: `assets/brand/ilya-yacine-create-portrait.jpg`
- Original dimensions: 969 × 1000 pixels.

Selection: a clear, approachable expression, a natural green background that complements the petrol and gold design, and a gaze toward the headline. Reviewed against the Urban Future speaker-profile portrait and the existing portrait and event photographs in the repository.

The image is stored locally and used unchanged. Cropping and feathered edges are controlled by responsive CSS; no facial retouching or generated portrait is used. Original source files and the About-page portrait remain unchanged.
